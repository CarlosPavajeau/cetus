---
title: Qué es Cetus
description: Facturación electrónica ante la DIAN por API, o desde la consola sin escribir código.
---

Cetus emite facturas, notas crédito y notas débito electrónicas ante la DIAN de Colombia. Le envías el
documento en JSON y Cetus hace el resto: lo valida, lo numera con tu resolución, genera el XML UBL 2.1, lo
firma con tu certificado, lo envía a la DIAN y le entrega al cliente el XML y el PDF por correo.

Sirve a dos tipos de usuario:

- **Quien integra un sistema** (un ERP, una tienda en línea, un software de punto de venta) y quiere
  facturar desde su código con una API REST.
- **Quien factura a mano**, sin sistema propio: emite desde la consola web con un formulario.

En ambos casos puedes empezar **hoy**, sin certificado ni habilitación ante la DIAN: cada cuenta nueva trae
un modo de simulación con una empresa de ejemplo lista para emitir.
